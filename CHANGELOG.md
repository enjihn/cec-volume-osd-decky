# Changelog

## 1.0.0-rc.1 - 2026-08-20

- First public release candidate.
- Added dynamic Valve `cecd` endpoint discovery and confirmed read-only volume
  state monitoring.
- Added the Steam-native number-free volume bar with continuous updates,
  five-second hold, fade revival, and mute presentation.
- Added in-game `Notification` composition with a fail-closed focused-window
  lease that does not claim Gamescope's MangoApp plane.
- Added SteamOS and Bazzite runtime-contract diagnostics.
- Removed machine-specific Guide-button input switching from the public plugin.
