# Decky Plugin Store status

This project is not submitted to the Decky Plugin Store in the release-candidate
stage.

The current official plugin-addition template includes a contributor
attestation about generative-AI authorship that cannot be truthfully selected
for this implementation. A Store submission must therefore wait for explicit
guidance or clearance from Decky maintainers, in addition to independent
SteamOS and Bazzite physical acceptance.

GitHub releases remain available for transparent testing in the meantime.
